# Omni Music Player (통합 음악 플레이어)

유튜브(YouTube Music) 및 로컬 저장소 음원을 한곳에서 재생하고, 자주 듣는 음악을 자동으로 모아주는 통합 음악 플레이어입니다.

## 주요 기능
1. **아날로그 LP 턴테이블 뷰**: 곡 선택 시 LP판이 턴테이블 위로 안착, 재생 시 톤암(바늘)이 LP 위로 이동하며 바이닐이 회전하는 감성 애니메이션
2. **우측 앨범 자켓 및 상세 정보**: 턴테이블 우측에 LP 슬리브 자켓과 아티스트/앨범 정보 표시
3. **하단 다른 곡 대기열**: 가로 스크롤 카드 캐러셀로 다른 곡들을 탐색하고 원클릭 전환
4. **내 저장소 음악 재생**: 로컬 디렉터리 내 음원 파일(MP3, WAV, FLAC 등) 자동 탐색 및 메타데이터/앨범아트 파싱
5. **유튜브 음원 스트리밍**: 유튜브 링크 또는 비디오 ID를 통한 즉시 재생
6. **음원 스트리밍 사이트 허브**: YouTube Music, 멜론, 벅스, 타이달 공식 웹 플레이어 접속 및 로그인 연동
7. **자주 듣는 음악(Top Played)**: 재생 횟수를 자동 집계하여 최다 청취 곡 모아듣기 지원
8. **즐겨찾기(Favorites)**: 마음에 드는 곡 보관함 관리
9. **DLNA / UPnP 캐스팅**: 로컬 네트워크 내 스마트 TV 및 무선 오디오/스피커로 음악 무선 전송

## 실행 방법
```bash
# 종속성 설치
npm install

# 서버 구동
node server.js
```
웹 브라우저에서 `http://localhost:3000`으로 접속하여 사용합니다.
