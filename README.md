# Omni Music Player (통합 음악 플레이어)

유튜브(YouTube Music) 및 로컬 저장소 음원을 한곳에서 재생하고, 자주 듣는 음악을 자동으로 모아주는 통합 음악 플레이어입니다.

## 주요 기능
1. **정밀 아날로그 톤암 시퀀스**:
   - [재생] 시 LP판이 먼저 회전하고, 톤암이 LP판 위에 완전히 내려앉은 후(1.2초 뒤)에 비로소 음악이 재생 시작
   - 음악 재생 진행률에 맞춰 톤암 바늘이 외주(13도)에서 내주(22.5도) 라벨 근처로 서서히 왼쪽으로 전진
   - 연속된 곡이 **동일 앨범**인 경우, 톤암의 이동 속도를 앨범 전체 곡 수에 맞추어 자동으로 조절하여 **해당 앨범이 모두 끝났을 때 비로소 라벨 이미지 근처에 도달**하도록 정밀 시뮬레이션
2. **실물 기반 4배 대형 LP 턴테이블 뷰**: 프리미엄 매트 블랙 실물 턴테이블(680x680px)과 고해상도 LP 레코드판
3. **우측 앨범 자켓 스탠드**: 실물 LP 슬리브 자켓 및 상세 음원 메타데이터 표시
4. **하단 다른 곡 대기열**: 가로 스크롤 카드 캐러셀로 다른 곡들을 탐색하고 원클릭 전환
5. **내 저장소 음악 재생**: 로컬 디렉터리 내 음원 파일(MP3, WAV, FLAC 등) 자동 탐색 및 메타데이터/앨범아트 파싱
6. **유튜브 음원 스트리밍**: 유튜브 링크 또는 비디오 ID를 통한 즉시 재생
7. **음원 스트리밍 사이트 허브**: YouTube Music, 멜론, 벅스, 타이달 공식 웹 플레이어 접속 및 로그인 연동
8. **자주 듣는 음악(Top Played)**: 재생 횟수를 자동 집계하여 최다 청취 곡 모아듣기 지원
9. **즐겨찾기(Favorites)**: 마음에 드는 곡 보관함 관리
10. **DLNA / UPnP 캐스팅**: 로컬 네트워크 내 스마트 TV 및 무선 오디오/스피커로 음악 무선 전송

## 실행 방법
```bash
# 종속성 설치
npm install

# 서버 구동
node server.js
```
웹 브라우저에서 `http://localhost:3000`으로 접속하여 사용합니다.
