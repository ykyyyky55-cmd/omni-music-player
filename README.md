# Omni Music Player (통합 음악 플레이어)

유튜브(YouTube Music) 및 로컬 저장소 음원을 한곳에서 재생하고, 자주 듣는 음악을 자동으로 모아주는 통합 음악 플레이어입니다.

## 주요 기능
1. **내 저장소 음악 재생**: 로컬 디렉터리 내 음원 파일(MP3, WAV, FLAC 등) 자동 탐색 및 스트리밍 재생
2. **유튜브 음원 스트리밍**: 유튜브 링크 또는 비디오 ID를 통한 즉시 재생
3. **자주 듣는 음악(Top Played)**: 재생 횟수를 자동 집계하여 최다 청취 곡 모아듣기 지원
4. **즐겨찾기(Favorites)**: 마음에 드는 곡 보관함 관리

## 실행 방법
```bash
# 종속성 설치
npm install

# 서버 구동
node server.js
```
웹 브라우저에서 `http://localhost:3000`으로 접속하여 사용합니다.
