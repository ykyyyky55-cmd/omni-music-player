# Omni Music Player (통합 음악 플레이어)

유튜브(YouTube Music) 및 로컬 저장소 음원을 한곳에서 재생하고, 자주 듣는 음악을 자동으로 모아주는 통합 음악 플레이어입니다.

## 주요 기능
1. **정밀 아날로그 톤암 시퀀스**:
   - [재생] 시 톤암이 먼저 LP판 시작 트랙 안쪽(16.5도)으로 부드럽게 이동
   - 톤암이 완전히 판 위에 안착한 직후 LP판이 회전하기 시작하며 동시에 음악 재생 시작
   - 음악 재생 진행률에 맞춰 톤암 바늘이 외주(16.5도)에서 내주(24.0도) 라벨 근처로 서서히 왼쪽으로 전진
   - 연속된 곡이 **동일 앨범**인 경우, 톤암의 이동 속도를 앨범 전체 곡 수에 맞추어 자동으로 조절하여 **해당 앨범이 모두 끝났을 때 비로소 라벨 이미지 근처에 도달**하도록 정밀 시뮬레이션
2. **33⅓ RPM / 45 RPM 회전수 선택**: 실제 턴테이블의 속도 스위치를 통해 33 RPM(1.8초) 및 45 RPM(1.33초) 회전 속도 자유 전환 지원
3. **실제 LP 카드보드 각진 자켓 디자인**: 두꺼운 스파인(책등)과 마감선, 날카롭고 빳빳한 모서리가 살아있는 실물 LP 슬리브 자켓 구현
4. **Web Audio API 아날로그 소리 설정**:
   - LP 바이닐 표면 크랙클 & 팝(바늘 긁힘/타닥거림) 노이즈 실시간 합성 및 볼륨 조절
   - 진공관 앰프의 따뜻한 중저음과 고역 롤오프를 재현하는 아날로그 웜 톤(Warm Tube EQ) 필터 제공
5. **실물 기반 4배 대형 LP 턴테이블 뷰**: 프리미엄 매트 블랙 실물 턴테이블(680x680px)과 고해상도 LP 레코드판
6. **하단 다른 곡 대기열**: 가로 스크롤 카드 캐러셀로 다른 곡들을 탐색하고 원클릭 전환
7. **내 저장소 음악 재생**: 로컬 디렉터리 내 음원 파일(MP3, WAV, FLAC 등) 자동 탐색 및 메타데이터/앨범아트 파싱
8. **유튜브 음원 스트리밍**: 유튜브 링크 또는 비디오 ID를 통한 즉시 재생
9. **음원 스트리밍 사이트 허브**: YouTube Music, 멜론, 벅스, 타이달 공식 웹 플레이어 접속 및 로그인 연동
10. **자주 듣는 음악(Top Played)**: 재생 횟수를 자동 집계하여 최다 청취 곡 모아듣기 지원
11. **즐겨찾기(Favorites)**: 마음에 드는 곡 보관함 관리
12. **DLNA / UPnP 캐스팅**: 로컬 네트워크 내 스마트 TV 및 무선 오디오/스피커로 음악 무선 전송

## 실행 방법
```bash
# 종속성 설치
npm install

# 서버 구동
node server.js
```
웹 브라우저에서 `http://localhost:3000`으로 접속하여 사용합니다.
